# Browser GTA V loader

Source for https://sniperscheats.lol/gta/. The page uses the unified builder userland connector, PS5Debug-NG 1.3.2, and the same exact 14 firmware targets as the desktop release. It does not launch a kernel jailbreak or reload etaHEN. The same executable fingerprints and Story Mode guards remain mandatory. Firmware table coverage is not hardware validation.

The hosted profile binaries and manifest come from the existing GTA menu build; their checksums are verified before injection. Original credits and licenses are retained in credits.html and LICENSE. Deploy these web files alongside the matching game binaries and the unified /builder/runtime routes.
