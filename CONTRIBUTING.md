# Contributing

Pull requests, reproducible reports and verified executable profiles are welcome.

Include PS5 firmware, title ID, full game version, PS5Debug-NG version, the exact menu action and any app error. Never upload game executables, archives, saves, memory dumps or account data.

Use Story Mode. Preserve exact executable fingerprints, duplicate-hook checks and compare-and-write verification. Do not broaden firmware or game support based only on matching title IDs. Test new profiles on hardware and describe what was verified.

For the app, run npm test and npm start. Native menu changes require Zig 0.14.1 and rebuilding both profiles with npm run build:menu. Keep authorship and third-party credits intact. Original contributions use GPL-3.0-or-later.
